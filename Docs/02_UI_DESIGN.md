# QuQuSQL 画面・UI/UX 仕様書

## 1. 画面デザインのコンセプト

提供された参考画面（OSqlEdit）の優れた点である **「視線移動の少なさ」「高い情報密度」「業務に集中できる落ち着いた視認性」** を継承しつつ、`egui` による高 DPI 対応・滑らかなスクロール・OSqlGrid 機能のシームレス統合を実現します。

- **デフォルトテーマ**: ライトテーマ（業務での長時間閲覧・画面共有でも見やすい高コントラスト配色）＋ ダークテーマ切替対応。
- **フォント設計**: UI 用プロポーショナルフォント＋エディタ/グリッド用等幅フォント（日本語はシステムフォントまたは軽量サブセットを遅延読み込み）。

## 3. 各エリアの詳細仕様

### 3.1 タイトルバー＆環境識別アクセント（誤操作防止）
- **タイトル書式**: `{接続表示名} ({USER}@{DB}) - QuQuSQL - [{アクティブタブ名}{未保存*}]`
- **環境識別カラー**:
  - 接続プロファイルに設定された「識別色」を、ウィンドウ最上部の 3px アクセントラインおよびツールバー右端の接続バッジ背景に適用。
  - 本番接続時は赤系アクセント＋確認ダイアログ強化など、視覚的に即座に判別可能にする。

### 3.2 メインワークスペースのタブ設計（SQL タブ ＆ Grid タブの統合）
左上ペインのタブバーでは、以下の 2 種類のタブを同居させます。
1. **SQL エディタタブ**（OSqlEdit モード）
   - 上部：SQL エディタ、下部：ログ / 実行結果グリッド / 実行計画 / `DBMS_OUTPUT` のサブタブ切替。
   - 実行結果グリッドタブ上から「この結果を編集モードで開く」を押すと、即座に編集可能グリッドへ切り替え可能。
2. **データグリッドタブ**（OSqlGrid 専用モード）
   - 右上オブジェクト一覧からテーブルをダブルクリック（または右クリック「グリッドで開く」）すると、広い作業領域を確保した専用グリッドタブが開く。
   - タブ上部にコンパクトな `WHERE` / `ORDER BY` バーとグリッド専用ミニツールバー（再検索、行追加、行削除、SQL プレビュー、Apply、フィルタ、転置、エクスポート）を配置。

### 3.3 左上ペイン：SQL エディタ
- **ルーラー**: エディタ上部に等幅文字幅基準で `0, 10, 20, 30...` の目盛りを描画（表示 ON/OFF 切替可）。
- **行番号ガター**: 左端に固定表示。エラー発生行には赤マーカー、ブックマーク行には青マーカーを表示。
- **不可視文字の可視化**:
  - 半角スペース: 薄い点（`·`）または下線記号
  - 全角スペース: 薄い四角（`□`）
  - タブ: 薄い矢印（`→`）
  - 改行: 薄い改行記号（`↵`）
- **補完ポップアップ**:
  - カーソル直下に軽量オーバーレイで表示。アイコン（Table / Column / Keyword / Func）、候補名、データ型・コメントを一覧表示し、`Tab` / `Enter` で確定。

### 3.4 左下ペイン：結果・ログ・実行計画ペイン
サブタブ形式で以下を切り替え可能（設定により「ログとグリッドを左右/上下に同時表示」も将来拡張可能）：
1. **ログタブ**:
   - タイムスタンプ（緑色コメント形式 `-- YYYY/MM/DD HH:MM:SS`）、実行 SQL、処理件数・経過時間（msec）、エラー詳細（`[row:1, col:15] ORA-00942: ...`）を追記表示。
   - エラー行をダブルクリックすると、SQL エディタの該当行・列へカーソルジャンプ。
   - 実行計画出力も OSqlEdit 同様のインデントテキスト形式でログ内に確認可能。
2. **結果グリッドタブ**:
   - `SELECT` 結果を高速仮想スクロールテーブルで表示。
   - ここから直接ソート、フィルタ、Excel コピー、CSV 出力が可能。
   - 編集可能クエリ（単一テーブル等）の場合は「編集ロック解除」ボタンでそのまま OSqlGrid 編集を開始可能。
3. **実行計画表示**:
   - 初期はログタブ内へ OSqlEdit 風のインデントテキスト形式で出力（将来拡張として専用ツリー表タブを追加可能）。
4. **出力（DBMS_OUTPUT）タブ（Phase 4 以降）**:
   - Oracle の `DBMS_OUTPUT` バッファ出力を専用表示（初期フェーズでは非表示）。

### 3.5 右上ペイン：オブジェクト一覧ペイン
- **ヘッダー操作部**:
  - `owner`: スキーマ選択コンボボックス（インクリメンタル検索可）
  - `type`: オブジェクト種別コンボボックス（`TABLE`, `VIEW`, `SYNONYM`, `INDEX`, `SEQUENCE`, `PACKAGE`, `PROCEDURE`, `FUNCTION`, `TRIGGER`, `MATERIALIZED VIEW` 等）
  - `filter`: 入力即座にオブジェクト名・コメント両方を部分一致（またはワイルドカード）絞り込み。履歴ドロップダウン＋`clear` ボタン付き。
- **一覧グリッド**:
  - 列: `OBJECT_NAME`（テーブル時は `TABLE_NAME`）, `COMMENTS`
  - 選択変更時に右下ペインの詳細を非同期で高速ロード（キャッシュ済みの場合は即時表示）。
  - 右クリックメニュー：
    - グリッドで開く（OSqlGrid モード）
    - SELECT 文を生成してエディタへ挿入
    - INSERT / UPDATE テンプレート生成
    - DDL（CREATE 文）を取得
    - オブジェクト名をコピー / コメントをコピー

### 3.6 右下ペイン：オブジェクト詳細ペイン
- **タブ**: `Column` | `Index` | `Constraint` | `R_Constraint` | `Trigger` | `Privilege` | `DDL`
- **フィルタ**: `filter` テキストボックス＋`clear` ボタン（カラム名・コメントを即時絞り込み）。
- **`Column` タブ列構成**:
  - `column name`（主キーには鍵アイコンまたは太字）
  - `data type`（`VARCHAR2`, `NUMBER`, `DATE` 等）
  - `length`（桁数・精度）
  - `nullable`（`Y` / `N`）
  - `comments`（論理名・備考）
- **操作**: カラム行をダブルクリックまたはドラッグ＆ドロップで SQL エディタのカーソル位置にカラム名を挿入（複数選択時はカンマ区切り挿入）。

### 3.7 ステータスバー（最下部）
左から右へ以下の情報を固定区画で表示：
1. **ファイル情報**: 文字コード・改行コード（例: `UTF-8, CRLF(\r\n)` / `SJIS, CRLF(\r\n)`）— クリックで変換メニュー
2. **接続情報**: 接続先識別子（例: `USER1@DBNAME`）＋ 接続状態インジケータ（緑丸＝接続中、赤＝切断）
3. **トランザクション状態**: `Tx: Clean` / `Tx: 未コミット変更あり (3件)`（未コミット時は強調色）
4. **カーソル / 集計情報**:
   - エディタフォーカス時: `1行, 16列`（選択時は選択文字数・行数も表示）
   - グリッドフォーカス時: `行 12 / 1,500 | 選択: 5セル | 合計: 12,400 | 平均: 2,480`

## 4. OSqlGrid 編集時の視覚フィードバック

| 状態 | 背景色（ライトテーマ目安） | 説明 |
| :--- | :--- | :--- |
| 通常セル | 白 / 交互行の極薄グレー | DB から取得した未変更データ |
| NULL 値 | 薄いグレー斜体 `<NULL>` | 空文字列 `""` と明確に区別 |
| 変更済みセル | 薄い黄色（`#FFF8C5`） | ローカルで値変更済み（未 Apply） |
| 新規追加行 | 薄い緑色（`#E6FFEC`） | INSERT 予定行（未 Apply） |
| 削除予定行 | 薄い赤色（`#FFEBE9`）＋ 取消線 | DELETE 予定行（未 Apply） |
| 読み取り専用列 | 極薄グレー文字 | 仮想列や ROWID/PK 不在時の編集不可セル |
| 検索ヒットセル | 鮮やかなオレンジ枠/ハイライト | グリッド内検索に一致したセル |

## 5. 主要ショートカットキー（カスタマイズ可能）

| 操作 | デフォルトキー | 備考 |
| :--- | :--- | :--- |
| SQL 実行（カーソル位置の文 / 選択範囲） | `Ctrl + Enter` または `F5` | OSqlEdit 互換で `F5` も割当 |
| SQL 連続実行（全スクリプト） | `Ctrl + Shift + Enter` | セミコロン区切りで順次実行 |
| 実行計画の取得 | `Ctrl + E` | Explain Plan |
| クエリ実行キャンセル | `Esc` | 実行中のみ有効 |
| コード補完の明示呼び出し | `Ctrl + Space` | 自動ポップアップも設定可 |
| パラメータヒント表示 | `Ctrl + Shift + Space` | 関数引数表示 |
| SQL 整形（フォーマット） | `Ctrl + Shift + F` | |
| 検索 / 置換 | `Ctrl + F` / `Ctrl + H` | エディタ・グリッド共通 |
| コミット / ロールバック | `Ctrl + Shift + C` / `Ctrl + Shift + R` | 誤爆防止のため Shift 併用 |
| オブジェクトブラウザ表示切替 | `F8` | 作業領域を広げたい時に使用 |
| グリッド内セルに NULL を設定 | `Ctrl + Delete` | 編集モード時 |
| データ編集ダイアログを開く | `F2` / `Shift + Enter` | 長文・CLOB 編集用 |
| 選択行の複製（グリッド） | `Ctrl + D` | テストデータ作成に便利 |
