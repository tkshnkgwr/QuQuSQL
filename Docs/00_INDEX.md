# QuQuSQL 設計・仕様書インデックス

**QuQuSQL (Quick Query SQL Tools)** は、Rust と `egui` で構築する超高速・省メモリなネイティブ SQL エディタ兼データグリッド編集ツールです。
定番ツールである **OSqlEdit** の軽快な SQL 開発体験と **OSqlGrid** の Excel ライクなデータ直接編集機能を単一アプリケーションに統合し、高速起動・低メモリ消費・誤操作防止を徹底した設計を目指します。

## 設計の基本方針（4つの柱）

1. **圧倒的な起動速度と省メモリ**
   - ネイティブバイナリ（Rust）＋イベント駆動描画（`egui`）により、アイドル時 CPU 0%・メモリ 30〜50 MB 級、コールドスタート 500 ms 以内を目指す。
2. **OSqlEdit × OSqlGrid の完全統合**
   - 従来の別アプリ連携によるログイン再入力やウィンドウ切替の手間を排除し、1 つのセッション・1 つのトランザクション上で SQL 実行からグリッド直接編集までをシームレスに完結させる。
3. **高情報密度・クラシック業務 UI**
   - 余白だらけのモダン Web 風 UI ではなく、OSqlEdit のような「一画面で SQL・結果・テーブル一覧・カラム定義をすべて見渡せる」実務特化レイアウトを採用する。
4. **疎結合なマルチクレート構成**
   - UI・SQL 解析・DB ドライバ・コアデータ構造を Cargo Workspace で分離し、ビルド高速化・テスト容易性・マルチ DB 拡張性を確保する。
