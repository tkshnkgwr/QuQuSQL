# QuQuSQL 製品要件・機能仕様書

## 1. プロダクトコンセプト

**QuQuSQL** は、データベース開発・運用・データメンテナンスの現場で「毎日ストレスなく使える」ことを最優先に設計された、Rust + `egui` 製デスクトップ SQL クライアントです。

- **OSqlEdit の軽快さ**（即起動、高速な補完・実行、実行計画、オブジェクトブラウザ）
- **OSqlGrid の編集力**（Excel ライクな表編集、差分のみ UPDATE、ROWID 対応、コピペ親和性）
- **Rust ネイティブの性能**（Electron / JVM 系ツールとは一線を画す低メモリ・高速レスポンス）

### 1.1 スコープ境界（やらないこと / 将来検討）

DB ツールの機能肥大化（「全部入り」による起動遅延・メモリ増大）を防ぐため、明確な線引きを設けます。

- **やらないこと（Non-Goals）**:
  - **ER 図の描画・モデリング機能**
  - **複雑なスキーマ比較（Schema Diff）・データ同期・マイグレーション機能**
  - BI グラフ描画や GUI ドラッグ＆ドロップ型のビジュアルクエリビルダー
- **将来検討（Future Backlog・初期フェーズ対象外）**:
  - **DB サーバー監視ダッシュボード**（セッション・ロック・表領域の監視など）
  - PL/SQL 開発支援（`DBMS_OUTPUT`・コンパイルエラー・デバッグ等）
  - マクロ機能（自動化スクリプト）
  - Oracle / SQLite 以外の RDBMS 対応

## 2. 非機能要件（パフォーマンス・品質目標）

| 項目 | 目標値 | 実現アプローチ |
| :--- | :--- | :--- |
| **コールドスタート時間** | **500 ms 以内**（初回ウィンドウ描画まで 200 ms 目標） | フォント・設定・DB ドライバの遅延初期化、軽量ネイティブ起動 |
| **アイドル時メモリ消費** | **30〜50 MB 以下** | Rust ネイティブ、`egui` テクスチャアトラス最適化、不要なキャッシュ非保持 |
| **大量データ取得時メモリ** | **10 万行 × 20 列で 150 MB 以下** | コンパクトセル表現、文字列インターニング、チャンク取得（ページング/フェッチ制限） |
| **グリッドスクロール性能** | **60 FPS 維持**（10 万行以上でもカクつかない） | 固定行高による完全仮想スクロール（描画対象は画面内行数のみ） |
| **アイドル時 CPU 使用率** | **0%** | `egui` のリアクティブ再描画（操作・非同期応答時のみ再描画） |
| **操作応答性** | 長時間クエリ実行中も UI フリーズなし | DB 通信を専用非同期ワーカーに完全分離、即時キャンセルボタン提供 |
| **誤操作防止** | 本番環境への誤更新・自動コミットを防止 | 接続先ごとの識別カラー・タイトル接頭辞、デフォルト手動コミット、発行 SQL プレビュー |
| **ターゲット OS** | **Windows 10 / 11 (x86_64)** 優先 | Windows 標準フォント活用・`%APPDATA%` 準拠（将来のクロスプラットフォーム拡張を意識した疎結合設計） |

## 3. 対応 DBMS 戦略

QuQuSQL の対応 RDBMS は **Oracle Database** と **SQLite** とします（将来的な他 DBMS 拡張も見据え、内部はドライバトレイトで抽象化します）。

| 優先度 | DBMS | 接続方式（確定） | 備考 |
| :---: | :--- | :--- | :--- |
| **最優先 (Phase 1)** | **Oracle Database** | **Pure Rust (`oracle-rs`)** | Instant Client 不要で単一バイナリ配布可能。`tnsnames.ora` 独自パース、ROWID、`DBMS_OUTPUT`、`DBMS_XPLAN`、コメント取得をサポート |
| **優先 (Phase 1)** | **SQLite** | `rusqlite`（bundled） | 外部 DB なしのローカルテスト・開発検証・軽量データ分析用として初期から同梱 |

> [!NOTE]
> Oracle 接続は **Pure Rust 方式（`oracle-rs`）** を採用し、Instant Client 依存を排除した軽量・高速な単一実行ファイル構成とします。`tnsnames.ora` の既存設定は `ququ-core` 内のパーサで自動解決して接続可能にします。

## 4. 機能仕様：OSqlEdit 相当機能（SQL エディタ・開発支援）

### 4.1 SQL エディタ機能
- **マルチタブ編集**: 複数の SQL ファイルをタブで管理。未保存マーク（`*`）表示、タブ並べ替え・複製。
- **基本・高度編集**:
  - 無制限 Undo / Redo
  - **矩形選択（ボックス選択）**（`Alt + ドラッグ` / `Alt + Shift + 矢印`）
  - 検索・置換（正規表現、大文字小文字区別、選択範囲内置換、全ハイライト）
  - コメントアウト / 解除トグル（`--` / `/* ... */`）
  - インデント一括増減、大文字・小文字変換
- **視認性支援**:
  - 行番号ガター表示、上部カラムルーラー表示（10 桁ごとの目盛り）
  - **空白（半角・全角スペース）・タブ・改行記号の可視化**
  - SQL / PL/SQL シンタックスハイライト（キーワード、文字列、数値、コメント、バインド変数、関数）
  - 括弧の対応ハイライト、現在行ハイライト
- **ファイル入出力**:
  - 新規作成時のデフォルト文字コードは **UTF-8**。
  - 文字コード自動判別・変換保存（UTF-8 / UTF-8 BOM / Shift_JIS(CP932) / EUC-JP）。
  - 改行コード判別・変換（CRLF / LF / CR）。
- **SQL 整形（フォーマッタ）**:
  - 選択範囲または全文の SQL を読みやすいインデント・改行ルールで自動整形。

### 4.2 入力支援・コード補完
- **キーワード補完**: SQL 予約語・組み込み関数のインクリメンタル補完。
- **コンテキスト認識補完**:
  - `FROM` / `JOIN` 句の後でテーブル名・ビュー名・シノニム名を補完（コメント併記）。
  - テーブル別名（エイリアス）を解析し、`alias.` 入力時に該当テーブルのカラム一覧をコメント付きで補完。
- **パラメータヒント**: 関数・プロシージャ呼び出し時に引数リストと型をポップアップ表示（`Ctrl + Shift + Space`）。

### 4.3 SQL 実行・検証・履歴
- **柔軟な実行モード**:
  - カーソル位置の 1 文を実行（`Ctrl + Enter` / `F5`）— **セミコロン `;` 区切り** で文境界を判定（文字列リテラル・コメント内の `;` は無視）
  - 選択範囲のみを実行
  - スクリプト全体の連続一括実行（エラー時停止 / 継続の選択可）
  - 実行中クエリの途中キャンセル（`Esc` または停止ボタン）
- **フェッチ制御・データ型表示規約**:
  - **初期フェッチ上限**: デフォルト **1,000 行** で一旦停止し、メモリ爆発を防止（画面上から「さらに取得」「全件取得」を選択可能。上限件数は設定変更可）。
  - **`DATE` / `TIMESTAMP` 表示**: デフォルト **ISO 形式（`YYYY-MM-DD HH:MM:SS`）**（設定で変更可能）。
  - **`NUMBER` 精度保証**: 16 桁以上の数値 ID や金額で浮動小数点の丸め誤差が起きないよう、内部的には **厳密な文字列表現（または Decimal）** で保持する。
- **バインド変数対応**:
  - `:var_name` 形式を自動検出し、実行時に値・データ型入力ダイアログを表示（前回値を記憶）。
  - スクリプト内コマンド（`!bind set var = val` 等）のサポート。
- **実行計画（Explain Plan）**:
  - 選択 SQL の実行計画を取得し、初期は **インデントテキスト形式**（OSqlEdit 同様のコスト・アクセスパス出力）で表示（Oracle は `EXPLAIN PLAN` および `DBMS_XPLAN` 対応。ツリー表形式は将来拡張）。
- **実行ログ・履歴**:
  - 実行日時・実行 SQL・処理件数・実行時間（ms）・エラー内容（エラー行・列番号付きでエディタへジャンプ可能）をログペインに出力。
  - SQL 実行履歴の自動保存と検索・再利用。
  - 実行結果ログのファイル自動保存オプション。

### 4.4 トランザクション＆セッション管理
- **1 ウィンドウ ＝ 1 接続（OSqlEdit 方式）**: 1 ウィンドウ内の全タブ（SQL タブ・Grid タブ）で単一セッション・単一トランザクションを共有する。これによりタイトル・環境識別カラーと接続先が常に 1 対 1 で一致し、本番誤爆を防ぐ（複数 DB を同時操作したい場合は別ウィンドウで起動）。
- **デフォルト手動コミット＆暗黙コミット防止**: 意図しないデータ確定を完全に防ぐ（詳細は [SECURITY.md](./SECURITY.md) の「データ破損・不意なコミット防止の絶対原則」を厳守）。
  - 明示的な **Commit** / **Rollback** 操作以外でアプリが勝手にコミットしない。
  - 未コミット DML がある状態での DDL 実行（Oracle の暗黙コミット発生）を事前検知して警告する。
  - `WHERE` 句なし `UPDATE` / `DELETE` の実行前確認ガードを備える。
- 未コミット変更がある状態でのウィンドウ終了・切断時に確認ダイアログを表示（デフォルトフォーカスは「キャンセル」固定）。
- セッション単位の読み取り専用モード（Read-Only 接続オプション）。

### 4.5 オブジェクトブラウザ・DB 検索・テーブル仕様書出力・DDL 編集
- **オブジェクト一覧（右上ペイン）**:
  - `owner`（スキーマ）切替、`type`（TABLE / VIEW / SYNONYM / INDEX / SEQUENCE / TRIGGER 等）切替。
  - インクリメンタル `filter` ＋ `clear` ボタン。
  - オブジェクト名と論理名（COMMENTS）の 2 列表示（ホバー時は指アイコン表示）。
  - `CREATE TABLE` 等の DDL 実行時、サイドバー表示中であれば自動でオブジェクト一覧を再取得して最新化。
  - **複数選択対応**（`Ctrl + クリック` / `Shift + クリック` / フィルタ結果全選択 ※Phase 3）。
  - ダブルクリックまたは右クリックメニューで「エディタへ名前挿入」「SELECT 文を挿入」「**SELECT 文を挿入 (全項目)**」「**DDL を取得（エディタへ貼り付け）**」「グリッドで開く」「**テーブル仕様書を出力**」。
- **オブジェクト詳細（右下ペイン）**:
  - タブ切替：`Column` / `Index` / `Constraint` / `R_Constraint` / `Trigger` / `Privilege` / `DDL(Source)`。
  - `filter` ＋ `clear` ボタンによるカラム絞り込み。
  - `Column` タブではカラム名・データ型・桁数・NULL 許可（`Y`/`N`）・コメントを表示。
  - `DDL(Source)` タブでは対象オブジェクトの DDL をプレビュー表示し、ワンクリックで SQL エディタタブへ開いて編集可能。
- **テーブル仕様書（テーブル定義書）の出力**:
  - オブジェクト一覧で選択した 1 つまたは複数のテーブルから、テーブル定義書を一括出力。
  - 出力項目：テーブル物理名・論理名（コメント）、カラム定義（物理名・論理名・データ型・桁数・PK・NOT NULL・デフォルト値・コメント）、インデックス定義、制約定義（PK / UK / FK / CHECK）。
  - 出力形式：
    - **Excel（`.xlsx`）**：目次シート＋テーブルごとの定義シート（Pure Rust 生成で Excel 本体不要）
    - **Markdown（`.md`）**：Git 管理・ドキュメント共有向け（1 ファイル集約 / テーブル別個別ファイルを選択可）
    - **CSV / HTML**（任意選択）
- **オブジェクト DDL の取得・編集**:
  - 選択したオブジェクト（テーブル・ビュー・インデックス・シーケンス・シノニム等）の DDL を取得し、新規 SQL エディタタブとして開いて直接編集・実行（反映）可能。
  - Oracle では `DBMS_METADATA.GET_DDL` を優先使用し、権限不足時はデータディクショナリ（`ALL_TAB_COLUMNS` / `ALL_CONSTRAINTS` / `ALL_INDEXES` / `ALL_VIEWS` 等）から DDL を自動再構築するフォールバックを実装。SQLite では `sqlite_master` から取得。
  - 本番識別環境での DDL 実行時や破壊的変更時には確認ダイアログを表示し、安全性を担保。
- **DB 内 Grep**:
  - `USER_SOURCE` / `ALL_SOURCE` 等のソース、テーブル/カラム名・コメントを横断検索。
- **PL/SQL 支援（Oracle・Phase 4 以降で対応）**:
  - 初期フェーズでは対象外とし、Phase 4 以降で `DBMS_OUTPUT` 出力・コンパイルエラー行ジャンプ・パッケージソース編集を段階実装。

### 4.6 接続管理・SQL ライブラリ
- **接続プロファイル管理（環境区分連動ガード）**:
  - 接続先リストの保存（初期は **パスワード都度入力** 方式とし、接続プロファイルにはホスト・ポート・サービス名・ユーザー名・環境区分・識別設定のみ保存。将来的に OS 資格情報ストア連携等を検討）。
  - Oracle `tnsnames.ora` の自動読み込み対応。
  - **環境区分（本番 / 検証 / 開発 / ローカル）の明示指定**: ログイン・接続登録画面で環境区分を選択でき、区分に応じて画面表示と安全動作が自動切り替えされる（詳細は [SECURITY.md](./SECURITY.md)・[GUI_DESIGN.md](./GUI_DESIGN.md) 参照）。
    - **本番環境**: 画面上部に **赤系の警告バナーを常時表示**、デフォルト **読み取り専用（Read-Only）接続**、**`COMMIT` / DML / DDL 実行時の強制確認ダイアログ**（例: `本番環境です。本当にコミットしますか？`、デフォルトフォーカスはキャンセル固定）。
    - **検証環境**: 黄〜オレンジ系の識別表示、設定に応じた確認ダイアログ。
    - **開発 / ローカル環境**: 青/緑系の識別表示、軽快な通常操作。
- **SQL ライブラリ**:
  - 指定フォルダ配下の定型 SQL ファイルをツリーメニューから即座に呼び出し・挿入・実行。

## 5. 機能仕様：OSqlGrid 相当機能（表形式データ閲覧・直接編集）

### 5.1 シームレスな起動とデータ取得
- オブジェクト一覧からテーブルを選択して「グリッドで開く」、またはエディタで実行した `SELECT` 結果をそのままグリッド編集モードへ移行可能。
- **抽出条件（WHERE / ORDER BY）指定**:
  - グリッド上部に `WHERE` / `ORDER BY` 入力欄を配置し、素早く再検索可能。
  - よく使う抽出条件の履歴保存・復元。
- **編集可能判定**:
  - 単一テーブルおよび更新可能ビュー（`USER_UPDATABLE_COLUMNS` 等）を判定。
  - 主キーがないテーブルでも、Oracle の **`ROWID`**（PostgreSQL は `ctid`）を内部保持することで安全に行を特定し編集可能とする。
  - 仮想列（Virtual Column）は自動的に読み取り専用として扱う。

### 5.2 Excel ライクなグリッド操作・編集
- **セル直接編集**:
  - キーボード主体で高速移動（矢印、`Tab`、`Enter`、`Home`/`End`、`Ctrl+矢印`）。
  - 複数セル範囲選択、行選択、列選択。
  - `NULL` 値と空文字 `""` の明確な視覚区別（薄いイタリック `<NULL>` 表示等）とワンキー `NULL` 設定。
- **専用データ編集ダイアログ**:
  - 長文テキスト・改行入り文字列・CLOB/JSON/XML データをポップアップエディタで快適に編集。
  - BLOB データのバイナリプレビュー・ファイルからのインポート/エクスポート。
- **行操作・一括変換**:
  - 新規行の挿入（末尾追加・現在行の上/下へ挿入）、行の複製、行の削除（削除マーク付与）。
  - 空行の一括削除。
  - 選択範囲の一括変換：大文字/小文字変換、全角/半角変換、トリム、**連番自動入力**。
- **Excel / CSV との高度なクリップボード連携**:
  - TSV（タブ区切り）＋セル内改行（ダブルクォートエスケープ）を正確に解釈。
  - ヘッダー付きコピー / 値のみコピー / INSERT 文コピー / `IN (...)` 句コピー。
  - **1 セルコピー → 複数選択セルへの一括ペースト**。
  - Excel からの複数行×複数列ペースト（不足行の自動追加対応）。

### 5.3 差分更新と安全性
- **変更トラッキングと視覚化**:
  - 追加行（緑系）、変更セル（黄系）、削除予定行（赤系・取り消し線）を色分け表示。
  - セル単位の Undo / Redo、変更のリバート（元に戻す）。
- **変更カラムのみの最小 UPDATE**:
  - 編集していないカラム（日付型や数値精度など）を巻き込まないよう、**変更されたカラムのみ**を `SET` 句に含めた `UPDATE` 文を生成。
- **発行 SQL プレビュー**:
  - DB へ反映（Apply）する前に、実際に発行される `INSERT` / `UPDATE` / `DELETE` 文の一覧を確認・コピーできるプレビューダイアログを提供。
- **トランザクション連携**:
  - Apply 実行後はセッションのトランザクション内で保留され、明示的な **Commit** または **Rollback** で確定・取消を行う。
  - 大量件数の保存中は進捗表示とキャンセルボタンを提供。

### 5.4 グリッド表示・分析・エクスポート
- **インメモリフィルタ＆ソート**:
  - 取得済みデータに対して、DB へ再問い合わせせずに列ごとのフィルタリング・昇順/降順ソートを実行。
- **グリッド内検索・ハイライト**:
  - マッチしたセルを色分けハイライトし、`F3` / `Shift+F3` で次・前の候補へ移動。
- **リアルタイム集計（ステータスバー）**:
  - 選択範囲の **選択セル数・数値件数・合計（SUM）・平均（AVG）・最小（MIN）・最大（MAX）** を即座に表示。
- **表示カスタマイズ**:
  - 列幅の自動調整（ダブルクリック / 一括調整）、列の固定（Freeze Panes）、列の表示/非表示。
  - セル内の改行・タブ記号の可視化トグル。
  - **転置表示（縦横入れ替え）**: カラム数が多い 1 レコードを縦 1 列で見やすく閲覧・編集する単票ビューモード。
- **エクスポート**:
  - CSV / TSV（文字コード・囲み文字・ヘッダー有無を指定可能）、INSERT 文 SQL、JSON、Markdown テーブル。

## 6. 開発ロードマップ（フェーズ計画）

いきなり全機能を実装せず、**「最速で動く・毎日使えるコア」** から段階的に積み上げます。
